# Bugfix Plan and Delivery

Read `../using-superplan/references/delivery-loop.md`, then apply:

- Input: `docs/superplan/human/bugs.md`
- Output: `docs/superplan/plans/bugs/`
- Plan type: `bugfix`

For an unrecorded bug, read `../using-superplan/references/intake-spec.md`
before diagnosis or planning.

When the root cause is not yet proven, read
[`references/debugging.md`](references/debugging.md) before planning.

Follow `../using-superplan/references/plan-spec.md` for ids, bug-specific
content, dependencies, and verification.
